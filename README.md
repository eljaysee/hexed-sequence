# hexed sequence

a small browser based generative midi tool for making dark, weird and slightly cursed music.

built around black metal, trap, witch house and dungeon synth ideas. generate sequences, mutate them, mess with the piano roll, preview them through a lo-fi synth and export the result as midi.

built with react, typescript, web audio api

## features

* procedural midi generation
* black metal, trap, arp, pad, drums and dungeon synth tracks
* interactive piano roll
* seed based generation and history
* mutations and humanization
* lo-fi web audio preview
* distortion, bitcrushing and filtering
* midi export
* runs entirely in the browser

made for experimenting, happy accidents and making things sound a little haunted.
